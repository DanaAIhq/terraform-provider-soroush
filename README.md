# Soroush Terraform provider

This repository publishes the Soroush Terraform provider: its signed release binaries, the
documentation shown on the Terraform Registry, and the modules that go with it. Its contents
are generated at each release, and the provider's source code is not published here.

```terraform
terraform {
  required_providers {
    soroush = {
      source = "DanaAIhq/soroush"
    }
  }
}
```

The first release has not been published yet.
